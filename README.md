# Depo — ديبو

تطبيق يبيع **رواجع المطاعم** و**عروض التجار** بأسعار مخفّضة. الانطلاق من الموصل.

## الحالة
- **المرحلة 0 (هسه):** الواجهات الأساسية للزبون ببيانات تجريبية: البداية، الرئيسية (رواجع/عروض)، تفاصيل العرض، السلة، إكمال الطلب (نقداً)، تسجيل برقم التلفون وقت الطلب، تتبع الطلب.
- **الجاي:** ربط Firebase (تسجيل الدخول، قاعدة البيانات، الإشعارات)، ثم واجهات المطعم والتاجر والمندوب والمشرف والمدير.

## شلون أحمّل التطبيق على تلفوني؟
كل مرة يتحدّث الكود، GitHub يبني ملف APK تلقائياً:
1. افتح صفحة المستودع ← **Releases** (على اليمين).
2. افتح آخر نسخة «Depo تجريبي» ونزّل `app-release.apk`.
3. افتحه على تلفون أندرويد ووافق على «تثبيت من مصادر غير معروفة».
